# AI vocabulary and phrase watchlists

From Wikipedia:Signs of AI writing. Use these to (a) spot a tell-cluster and (b) find plainer replacements. A word here is not banned — it's a flag. Judge by density and context: a single "crucial" is nothing; a paragraph stacked with delve/underscore/tapestry/pivotal/robust is a strong tell. Fix the habit, not just the word.

## Master list of overused words ("words to watch")

Additionally (esp. starting a sentence), align with, boasts (meaning "has"), bolstered, crucial, delve, emphasizing, enduring, enhance, fostering, garner, highlight (as a verb), interplay, intricate / intricacies, key (as an adjective), landscape (as an abstract noun), meticulous / meticulously, pivotal, robust, showcase, tapestry (as an abstract noun), testament, underscore (as a verb), valuable, vibrant.

Also commonly cited elsewhere and worth watching: leverage, multifaceted, seamless, realm, navigate (figuratively), foster, cultivate, resonate, profound, groundbreaking, renowned, nestled, "rich history", "diverse array", "stands as", "plays a vital/significant role", "it's worth noting", "in today's world / digital age", "when it comes to", "a testament to", "the world of".

### Plain replacements (illustrative)
- delve into → look at, examine, go into
- underscore / highlight / emphasize → show, point to (often just delete the clause)
- pivotal / crucial / vital / key → important, main, or cut
- robust → strong, solid, reliable
- leverage → use
- foster / cultivate → encourage, build, support
- showcase → show, display
- tapestry / landscape / realm (abstract) → usually delete or name the actual thing
- boasts / features / offers → has
- seamless → smooth, or cut
- a testament to → shows, or cut
- navigate (figurative) → deal with, handle

## Era breakdown (rough, not hard cutoffs)

The vocabulary distribution differs by model and has drifted over time. Use this only to gauge whether text reads as "earlier" or "later" LLM output.

- **Earlier era (≈2023–early 2024):** heavy figurative "delve", "underscore", "tapestry", "testament", "intricate", "vibrant", "rich", lots of em-dash flourishes and blatant superlatives. ("delve" famously peaked here, then dropped sharply through 2025.)
- **Later era (≈2025+):** more subtle positivity, fewer obvious superlatives, more canned notability/attribution language ("independent coverage", "profiled in"), often suppressed em dashes and reduced boldface in models tuned against those habits.

Keep context in mind: e.g. "underscore" can legitimately mean a literal underline or incidental music; "landscape" can be literal terrain. Flag the *figurative/abstract* uses.

## Content-specific phrase watchlists

These bundles tend to appear together within particular content tells.

**Significance / legacy padding:** stands / serves as; is a testament / reminder; a vital / significant / crucial / pivotal / key role / moment; underscores / highlights its importance / significance; reflects broader; symbolizing its ongoing / enduring / lasting; contributing to the; setting the stage for; marking / shaping the; represents / marks a shift; key turning point; evolving landscape; focal point; indelible mark; deeply rooted.

**Canned notability / media coverage:** independent coverage; local / regional / national / [country] media outlets; music / business / tech outlets; profiled in; written by a leading expert; active social media presence.

**Superficial trailing analysis:** highlighting / underscoring / emphasizing …; ensuring …; reflecting / symbolizing …; contributing to …; cultivating / fostering …; encompassing …; valuable insights; align / resonate with.

**Promotional / brochure:** boasts a; vibrant; rich; profound; enhancing; showcasing; exemplifies; commitment to; natural beauty; nestled; in the heart of; groundbreaking; renowned; featuring; diverse array.

**Vague attribution:** industry reports; observers have cited; experts argue; some critics argue; "several sources / publications" (when few or none are actually cited); "such as" before an exhaustive list.

**Outline-shaped conclusion:** "Despite its … faces several challenges …"; "Despite these challenges …"; "Challenges and Legacy"; "Future Outlook"; "Future Prospects".

**Copula avoidance (replace with is/are/has):** serves as / stands as / marks / represents [a]; boasts / features / maintains / offers [a]; refers to.

## How to use this file

1. Scan the target text against the master list and the relevant phrase bundle.
2. If you find a cluster, that confirms the tell — now fix the *structure*, not just the words (see `ai-tells.md` and the SKILL checklist).
3. Replace figurative AI vocabulary with plain equivalents, and reduce the overall count.
4. Never fabricate specifics to replace a vague phrase; cut the unsupported claim instead.
